# Estatística

A estatística é uma ferramente que envolve a organização, a interpretação e a apresentação de informações e dados. Ela ajuda a organizar os dados para entender como as informações se relacionam através de algum padrão e, por meio disso, tomar decisões.

## Análise Estatística

É o processo de extrair informações "escondidas" dos dados, que podem ser úteis para responder à pergunta investigativa.

### Estatística Descritiva

A estatística descritiva serve puramente para organizar e representar os dados.

### Estatística Inferencial

A estatística inferencial trabalha com probabilidades. Ela é responsável por inferir dados a partir de informações já obtidas.

## Dados

Os dados consistem em informações provenientes de observações, contagem, medidas ou respostas.

## População e Amostra

A população diz respeito a todos os elementos que podem participar da pesquisa; a amostra representa a população de forma fiel, isso é feito através de **técnicas de amostragem**:

- Amostragem Aleatória Simples;
- Amostragem Aleatória Estratificada;
- Amostragem Sistemática;
- Amostragem por Conglomerado.

## Fenômeno

O fenômeno é o acontecimento ou processo da realidade que queremos analisar através dos dados.

## Variável Estatística

É a característica ou propriedade que será estudada/observada na população. São divididas nos seguintes tipos:

- Qualitativas: Nominais e Ordinais;
- Quantitativas: Discretas e Contínuas.

A variável é qualitativa quando a resposta é uma palavra; e quantitativa quando é um número.

Quando a resposta é um número natural, a variável é quantitativa discreta; quando é um número decimal, é quantitativa contínua.

Quando a resposta é uma palavra que possui ordenação, a variável é qualitativa ordinal; quando não é ordinal, é qualitativa nominal.

## Fases do Método Estatístico

O método estatístico é subdividido nas seguintes fases:

- Definição do problema;
- Planejamento da pesquisa;
- Coleta dos dados;
- Apuração dos dados;
- Exposição dos dados;
- Análise dos resultados.

# Exercícios

## Ex. 1

**Classifique cada um dos dados abaixo como qualitativo nominal, qualitativo ordinal, quantitativo discreto e quantitativo contínuo:**

**a) Número de downloads de um aplicativo em um dia.**

Quantitativo discreto.

**b) Sistema operacional utilizado por um usuário (Windows, Linux, MacOS).**

Qualitativo nominal.

**c) Tempo de execução de um algoritmo (em segundos).**

Quantitativo contínuo.

**d) Nível de satisfação do usuário (baixo, médio, alto).**

Qualitativo ordinal.

**e) Número de erros registrados em um servidor.**

Quantitativo discreto.

## Ex. 2

**Um professor deseja estudar o tempo que estudantes levam para executar um programa em Python durante um laboratório. Ele registrou os seguintes tempos (em segundos):**

**12, 15, 11, 14, 13, 12, 16, 14, 13, 12**

**Construa uma tabela simples de dados e identifique:**

**a) Qual é o fenômeno estudado.**

Tempo que estudantes levam para executar um programa em Python durante o laboratório.

**b) Qual é a variável observada.**

Tempo de execução do programa.

**c) Qual é o tipo de dado.**

Quantitativo contínuo.
